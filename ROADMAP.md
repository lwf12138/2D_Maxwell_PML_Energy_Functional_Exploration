# Roadmap

1. Verify the displayed Maxwell--PML model with `P`, `P_{z,1}`, `P_{z,2}`, `Q_x`, `Q_y`.
2. Start with the `alpha=1` polarization law and compute the electromagnetic-plus-polarization energy derivative.
3. Test shifted magnetic variables `M_x`, `M_y`.
4. Search for a Baffet-type energy using shifted variables, cross terms, or time-integrated auxiliaries.
5. Separate constant-coefficient, separated-variable, and fully variable absorption profiles.
6. If monotonicity fails, formulate a bounded/no-abnormal-growth estimate, a dissipative Gronwall estimate, or a verified obstruction.
7. Add the fractional `0<alpha<1` memory only after the `alpha=1` PML mechanism is understood.
