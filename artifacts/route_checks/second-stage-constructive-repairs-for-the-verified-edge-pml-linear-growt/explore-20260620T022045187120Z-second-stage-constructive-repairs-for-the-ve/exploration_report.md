## Core obstruction

For an x-edge PML with constant `sigma_x=s>0`, `sigma_y=0`, the verified shift gives

```text
M_x = Q_x + mu*(s/epsilon_0)*H_x,
H_{x,t} = M_x / mu,
M_{x,t} = 0
```

on the spatially constant `E=0` mode. If `M_x(0)` is nonzero, `H_x` and `Q_x` grow
linearly. The y-edge has the symmetric obstruction with `M_y`.

Thus the second-stage problem is not mainly a Debye polarization problem. The object
that must be controlled is the zero-transverse-frequency shifted magnetic invariant
in the edge layer. Any constructive repair must do at least one of the following:

1. remove the invariant from the admissible data;
2. damp the invariant by modifying the shifted/auxiliary equation;
3. split or augment the field variables so that the edge zero-frequency mode is not a
   free Jordan block.

## Route A: compatibility and quotient restrictions

This route keeps the source equations but narrows the data class.

Natural restrictions:

- In an x-edge region (`sigma_x>0`, `sigma_y=0`), require the obstructing kernel
  projection of `M_x=Q_x+mu*(sigma_x/epsilon_0)H_x` to vanish on the transverse
  zero mode. For constant coefficients and periodic/closed transverse geometry, this
  is the `y`-mean of `M_x`.
- In a y-edge region, impose the analogous zero-mode restriction for
  `M_y=Q_y+mu*(sigma_y/epsilon_0)H_y`.
- For the electric PML corner auxiliaries, impose physical zero-auxiliary
  compatibility where their source coefficient `sigma_x sigma_y` vanishes, or else
  carry their constant modes as prescribed forcing data outside the coercive energy.

Why this is non-obvious: the compatibility should not be stated as simply
`M_x(0)=0` pointwise. The full edge equation is

```text
M_{x,t} = -(sigma_x/epsilon_0) * partial_y E
```

when `sigma_y=0`, so nonzero transverse modes can be generated by the Maxwell
dynamics. The real obstruction is the transverse kernel, not every value of `M_x`.

Concrete falsification/proof test:

- Freeze constant x-edge coefficients and Fourier transform in the transverse
  variable. For nonzero transverse frequency `k`, the lossless magnetic-edge
  subsystem factors as

```text
(lambda + b) * (epsilon * lambda^2 + k^2/mu) = 0,
b = sigma_x/epsilon_0,  epsilon = epsilon_0 epsilon_infty.
```

This has a damped eigenvalue and two imaginary oscillator eigenvalues, but no Jordan
linear-growth block. The zero-frequency block is the only source of the verified
linear mode in this simplified subsystem.

Expected outcome: a uniformly bounded or non-growing estimate on a quotient space, or
on data satisfying a zero-transverse-mode compatibility condition. This is not an
unconditional repair for arbitrary eight-variable source-model data.

## Route B: shifted-variable or MPML-style damping

This route changes the source model minimally by adding damping to the shifted
magnetic variables that are undamped in edge layers:

```text
M_{x,t} = a_x partial_y E - gamma_x M_x,
M_{y,t} = -a_y partial_x E - gamma_y M_y,
```

with `gamma_x` positive in x-edge regions and `gamma_y` positive in y-edge regions.
The source model has `gamma_x=sigma_y/epsilon_0` and `gamma_y=sigma_x/epsilon_0`,
which is exactly why an x-edge leaves `M_x` undamped.

Zero-mode check:

```text
H_t = M/mu,
M_t = -gamma M.
```

This semigroup is bounded and admits a positive quadratic Lyapunov functional with a
cross term. If

```text
Pmat = [[p, p/(mu gamma)], [p/(mu gamma), q]],
q > p/(mu^2 gamma^2),
```

then `A^T Pmat + Pmat A <= 0` for the matrix
`A=[[0,1/mu],[0,-gamma]]`, with strict dissipation on the `M` component. This removes
the Jordan block while allowing a non-decaying final magnetic offset.

Expected outcome: proof of uniform boundedness for the repaired edge zero mode, then a
PDE energy with small/structured cross terms for nonzero modes. The main risk is that
the derivative couplings `M_x partial_y E` and `M_y partial_x E` require either a
derivative energy, coefficient restrictions, or a CFS/split formulation to close.

## Route C: CFS or split-field formulation

This route changes the PML formulation rather than only post-processing the source
variables. The repair target is a CFS/split-field PML whose auxiliary memories have a
positive frequency shift, for example replacing edge memory decay rates by
`sigma_i/epsilon_0 + alpha_i` with `alpha_i >= alpha_*>0` in the relevant memory
equations.

The first-stage obstruction says exactly what CFS must fix: zero temporal frequency in
an edge layer should no longer produce a free shifted magnetic invariant. A CFS shift
does this at the pole level by moving `1/lambda` memory factors to
`1/(lambda+alpha)`.

Proof plan:

- Write the repaired constant-coefficient edge system in split variables.
- Verify the zero-frequency ODE has no Jordan block.
- Build a positive symmetrizer or Lyapunov matrix for every frozen Fourier mode.
- Only after the constant-coefficient edge/corner test passes, attempt variable
  coefficient estimates. Variable profiles may need derivative weights or a bounded
  perturbation argument.

Expected outcome: the most plausible route to a monotone or uniformly bounded energy
for arbitrary repaired-model data. It is not a proof about the original source model;
it is a constructive modified-model proposal.

## Route D: corner-first symmetrizer

The verified obstruction is an edge phenomenon. In constant corners with both
absorptions positive, the shifted variables satisfy

```text
M_{x,t} = a_x partial_y E - (sigma_y/epsilon_0) M_x,
M_{y,t} = -a_y partial_x E - (sigma_x/epsilon_0) M_y.
```

Therefore both shifted magnetic memories are damped. A focused corner task should
search for a frozen-Fourier Lyapunov matrix before attempting a physical-space local
energy. The theorem-search hit on Cartesian PML corners suggests that special corner
coefficient relations, especially symmetric corners, may admit stronger stability than
general asymmetric coefficients.

Risk: a corner-only result does not repair the verified edge obstruction and cannot
serve as goal success for edge-inclusive source data.

## Current assessment

The current terminal artifact is a verified first-stage obstruction plus Gronwall
estimate. It is only a partial solution for second-stage constructive repairs. The
source equations themselves can likely be salvaged only under compatibility/quotient
restrictions. For arbitrary eight-variable data, a genuine repair must modify the
edge shifted-memory dynamics, most plausibly via MPML/CFS damping or a split-field
formulation.
