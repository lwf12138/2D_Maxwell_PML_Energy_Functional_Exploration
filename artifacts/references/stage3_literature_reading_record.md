# Stage-3 Literature Reading Record

Problem id: `2d_maxwell_pml_energy_functional_exploration`

Scope: readings used for the stage-3 perfect-matching and dissipative-energy
analysis.  Page numbers for PDFs are the extractor/PDF page numbers unless an
internal printed page number is explicitly visible.  Some mathematical displays
in the local PDFs are only partially represented by `pdfminer`; in those cases I
use the surrounding prose and section labels only, and derive the algebra in the
stage-3 proof artifacts rather than quoting unreadable formulas.

| Joly (2012), elementary PML introduction | PDF pp. 6--7, 9--11, 14--17, 19--20 | PML is characterized by impedance matching/zero reflection; construction via complex coordinate change \(x\mapsto x+(i\omega)^{-1}\int\sigma\); in 2D only the derivative in the PML direction is stretched; adding isotropic damping to all components is not generally perfectly matched. | Defines the planar-interface/stretched-coordinate test used in the v2 mismatch proof. |
| Baffet--Grote--Imperiale--Kachanovska (2019) | PDF pp. 4--11 and 35 | For the second-order wave PML, a non-naive augmented energy with shifted variables and time integrals decays for constant damping; variable/piecewise damping introduces gradient/interface remainders, so monotone decay is not automatic. | Provides the model for what a genuine dissipative PML energy must contain and justifies constant-coefficient scope for sharp identities. |
| Bécache--Fliss--Kachanovska--Kazakova (2021) | PDF pp. 2--8 | Classical Cartesian PML for Maxwell can become unstable in some anisotropic 3D diagonal media; stability is model-dependent and tied to backward waves/group velocity. | Used as a caution that perfect matching and stability are distinct properties. |
| Bécache--Kachanovska--Wess (2023) | PDF pp. 4--10 and references pp. 39--40 | For dispersive waveguides, the PML is derived in the Laplace domain after eliminating polarization; the stretch uses \(1+\sigma/(s\zeta(s))\). Material passivity/admissibility and the choice of \(\zeta\) matter for stability; the paper gives a time-domain auxiliary-variable PML and exponential truncation error theorem. | Supports using the physical material law \(A(s)\) in the stretched-coordinate derivation, rather than replacing it by \(A(s+\rho)\). |
| Huang--Li--Liu (2023) | PDF pp. 1--6 | Equivalent Berenger PML models have nontrivial stability analysis; an explicit unconditionally stable finite-element scheme is built for an equivalent model, while variable-damping energy stability remains difficult. | Used to classify equivalent Berenger/ADE systems as plausible but not automatically monotone in the simple \(L^2\) energy. |
| Meza-Fajardo--Papageorgiou (2008), local `A_Nonconvolutional...pdf` | PDF pp. 1--6, 8--10, 19, 23, 26 | M-PML adds damping in multiple coordinate directions; stability can improve, but it is a modified absorbing layer with parameters chosen for spectral stability. | Used for the MPML repair option and for the statement that stabilizing modifications can sacrifice exact perfect matching. |
| Correia--Jin (2006) | PDF pp. 1--5 | Regular PML, CFS-PML, and second-order PML have different absorption strengths; CFS helps evanescent waves but can hurt low-frequency propagating waves, while higher-order PML combines mechanisms. | Used for the CFS/ADE candidate classification, not as an energy proof. |
| Feng--Li (2013) | PDF pp. 1--4 and 6--9 | Higher-order stretched-coordinate PML can be implemented through ADE variables and can improve late-time/evanescent absorption in computations. | Used to justify an ADE time-domain realization of rational stretch factors. |
| Ping--Xu--Mao--Yang (2014) | PDF pp. 1--3 and 8--10 | Second-order M-PML is reported as long-time stable and efficient in elastic simulations, while classical PML can show late-time instability. | Used as supporting context for MPML as a stability-oriented, not exact-matching-first, repair class. |
| Xie--Zheng--Cristini--Zhang (2023) | PDF pp. 1--7 and 13 | M-PML is explicitly described as losing perfect matching because of multiaxial stretching, though frequency shifting improves near-grazing and long-time behavior. | Used to state that MPML-type repairs should be labeled stable/absorbing, not perfectly matched. |
| `references/main.pdf` | PDF pp. 4--6, 38--40, 42--48, 54--56 | Local manuscript derives UPML/Cole--Cole frequency-domain forms, 2D energy boundedness, stretched-coordinate PML notes, and CFS-PML attempts; formulas are partly unreadable in extraction. | Used as local project context; no independent formula claim is taken from unreadable displays. |
| `references/Super.pdf` | PDF pp. 1--5, 20, 30, 35--38 | Local superconvergence notes for DG methods with PML; mostly numerical-analysis context rather than continuous matching algebra. | Not used as support for perfect matching; recorded because it was requested among local PDFs. |
| `references/Thesis.pdf` | PDF pp. 80--86, 111--112, 144--149, 151--155 | Local thesis states one-dimensional C-CPML discrete energies can be strictly dissipative; two-dimensional C-CPML continuous stability is proved by a Gronwall estimate, with monotone energy difficult due to anisotropic PML magnetic terms. | Supports the report's distinction between 1D strict dissipation and 2D finite-time stability for the old C-CPML-style system. |
