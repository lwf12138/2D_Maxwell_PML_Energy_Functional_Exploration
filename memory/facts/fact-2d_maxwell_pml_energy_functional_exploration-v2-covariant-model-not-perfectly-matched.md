## statement

For a planar x-interface with constant layer coefficient rho_x=rho>0, rho_y=0, Laplace parameter Re s>0, and tangential Fourier number k_y, the physical Maxwell-Debye admittance is Y0^2=A(s)/mu+k_y^2/(mu^2 s^2), where A(s)=epsilon0 epsilon_infty+chi/(1+tau s).  The v2 covariantly damped model has Yrho^2=A_rho(s)/mu+k_y^2/(mu^2 s(s+rho)), where A_rho(s)=epsilon0 epsilon_infty+chi/(1+tau(s+rho)).  Hence Yrho^2-Y0^2=-rho[chi tau/(mu(1+tau(s+rho))(1+tau s))+k_y^2/(mu^2 s^2(s+rho))], which is generically nonzero.  Therefore the interface reflection coefficient (Y0-Yrho)/(Y0+Yrho) is generically nonzero: the model is dissipative but not perfectly matched.
